## 🔒 Security & Performance Features
- **HTTPS Enforcement:** Auto-redirection from HTTP to HTTPS with TLS 1.3/1.2 support.
- **Security Headers:** Configured via Express Helmet (`Content-Security-Policy`, `Strict-Transport-Security`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`).
- **Input Sanitization:** Server-side and client-side XSS escaping and phone regex validation.
- **Rate Limiting:** Protects API endpoints against spam and DoS attacks using `express-rate-limit`.

## 🚀 Deployment & Local Setup

### Live Production Deployment
Hosted on Vercel Edge Network: [https://smart-suraksha-rakshak.vercel.app/](https://smart-suraksha-rakshak.vercel.app/)

### Local Development Setup
```bash
# 1. Clone the repository
git clone https://github.com/Komal251205/SSR.git
cd SSR

# 2. Install dependencies
npm install

# 3. Start the secure HTTPS server
node server.js
```

Access locally at: `https://localhost:3000`
